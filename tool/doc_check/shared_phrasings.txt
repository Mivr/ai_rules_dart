A `dart_package_metadata` declaring this Dart package's `package_name` and `language_version`. Mutually exclusive with the inline `package_name` / `language_version` attributes: set `package` to state those facts once for every rule building this package, or set them inline, but never both. Referencing a target is what lets rules in *different* BUILD files share one declaration, which a macro cannot do. => one declaration, `PACKAGE_IDENTITY_ATTRS` in `dart/private/common.bzl`, that every rule building part of a Dart package loads unchanged; the attribute means the same on each

Optional: set it (or `language_version`, or `package`) only to make this target a member of a package rooted at its Bazel package directory, as a `dart_library` there would be; left unset, the target contributes no package and its entrypoint takes the version of the package whose root contains it. Set this or `package`, not both. => one declaration, `EXECUTABLE_PACKAGE_ATTRS` in `dart/private/executable_package.bzl`, shared by `dart_binary`, `dart_test`, `dart_js_binary` and `dart_wasm_binary`, which take the identity attributes identically
